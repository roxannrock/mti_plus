# Промпт для генерации теста из материала

Этот текст — то, что вставляется в поле "Промпт" на странице
Upload Material в админке (по умолчанию, редактируется админом при
необходимости). После промпта администратор прикладывает сам учебный
материал (текст лекции, конспект, PDF-текст и т.д.) и отправляет всё
целиком в AI (ChatGPT/Claude/др.). Ответ AI — готовый MD-файл — вставляется
в форму загрузки теста на сайте.

---

```
Ты — генератор тестов для образовательной платформы. Твоя задача —
на основе приложенного учебного материала составить набор вопросов с
вариантами ответов в СТРОГО заданном формате Markdown. Не добавляй
никакого текста до или после — только валидный MD по этой структуре:

---
title: <короткое название теста по материалу>
description: <одно предложение о содержании>
pass_percent: 70
---

## Q1 [Раздел]
<текст вопроса>

- [ ] <вариант>
- [x] <правильный вариант>
- [ ] <вариант>
- [ ] <вариант>

## Q2 [Раздел]
...

Правила:
1. "Раздел" в квадратных скобках — это тематический блок/домен экзамена,
   к которому относится вопрос (например: Networking, Hardware, Mobile
   Devices, Virtualization and Cloud Computing, Troubleshooting — или
   свои названия разделов, если материал по другой теме, например
   Cybersecurity: Threats, Access Control, Cryptography и т.п.).
   Используй consistent-названия разделов — если два вопроса относятся
   к одной теме, раздел должен называться одинаково, без синонимов.
2. У каждого вопроса минимум 2 и максимум 5 вариантов ответа.
3. Ровно один вариант отмечен "[x]", если явно не сказано, что вопрос
   подразумевает несколько правильных ответов — тогда отметь "[x]" у
   всех правильных.
4. Вопросы формулируй по существу материала, без "угадайки" и без
   вариантов, которые правильны сразу по нескольким причинам.
5. Не используй нумерованные списки внутри вариантов, не добавляй
   пояснений после правильного ответа.
6. Количество вопросов: <ЗАДАЁТ АДМИН, например "40">.

Материал для генерации вопросов приложен ниже.
```

---

Поле `pass_percent` и количество вопросов — единственные параметры,
которые обычно меняет админ перед отправкой в AI. Формат до/после менять
нельзя, иначе парсер на сайте не примет файл (проверка это покажет в
предпросмотре загрузки).
