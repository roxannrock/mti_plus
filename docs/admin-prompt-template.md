# Промпт для генерации теста из материала

Этот текст — то, что показывается в блоке «Нет CSV? Сгенерировать через
AI» на странице Upload Material в админке (по умолчанию, редактируется
админом при необходимости). После промпта администратор прикладывает сам
учебный материал (текст лекции, конспект, PDF-текст и т.д.) и отправляет
всё целиком в AI (ChatGPT/Claude/др.). Ответ AI — готовый CSV-файл —
загружается в форму на сайте.

---

```
Ты — генератор тестов для образовательной платформы. Твоя задача —
на основе приложенного учебного материала составить набор вопросов с
вариантами ответов и выдать их CSV-файлом (кодировка UTF-8, разделитель —
запятая). Не добавляй никакого текста в сам файл — только CSV по этой
структуре:

раздел,вопрос,A,B,C,D,E,ответ
Networking,Какой порт по умолчанию использует HTTPS?,21,80,443,22,,C
Hardware,"Какие из этих устройств — устройства хранения?",SSD,RAM,HDD,CPU,,"A,C"

Правила:
1. Первая строка — ровно такой заголовок, как выше.
2. "раздел" — тематический блок/домен экзамена, к которому относится
   вопрос (например: Networking, Hardware, Mobile Devices — или свои
   названия, если материал по другой теме). Используй одинаковое
   название раздела для вопросов одной темы.
3. У каждого вопроса минимум 2 и максимум 5 вариантов (колонки A–E);
   лишние колонки вариантов оставляй пустыми.
4. "ответ" — буква правильного варианта. Если вопрос подразумевает
   несколько правильных ответов — перечисли буквы через запятую в
   кавычках, например "A,C".
5. Любое значение, содержащее запятую или кавычки, бери в двойные
   кавычки; кавычки внутри значения удваивай ("").
6. Вопросы формулируй по существу материала, без "угадайки".
7. Количество вопросов: РОВНО <ЗАДАЁТ АДМИН, например "40"> — не меньше и не больше. Прежде чем
   выдать файл, пересчитай строки с вопросами и, если количество не совпадает,
   добавь или убери вопросы.

Материал для генерации вопросов приложен ниже.
```

---

Количество вопросов — параметр, который обычно меняет админ перед
отправкой в AI. Проходной балл и название теста задаются в форме
загрузки, а не в файле. Формат CSV см. в `docs/csv-template-spec.md` —
если AI его нарушит, сайт покажет ошибки с номерами строк.
