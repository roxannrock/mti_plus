# Формат CSV-теста

Тест загружается в админке (**Upload Material**) одним CSV-файлом.
Файл целиком парсится бэкендом (`backend/src/lib/csvParser.ts`).
Шаблон для скачивания — `frontend/admin/public/test-template.csv`,
полный пример — `docs/example-comptia-a-plus.csv` (90 вопросов).

## Требования к файлу

- Кодировка **UTF-8** (BOM допускается). В Excel: «Сохранить как» →
  «CSV UTF-8 (разделитель — запятая)».
- Разделитель — **запятая**. Файл с `;` (так сохраняет Excel с русской
  локалью) тоже принимается — разделитель определяется по первой строке.
- Значение с запятой, кавычкой или переносом строки берётся в двойные
  кавычки, кавычки внутри удваиваются: `"Он сказал ""да"", а потом ушёл"`.

## Структура

```
раздел,вопрос,A,B,C,D,E,ответ
Networking,Какой порт по умолчанию использует HTTPS?,21,80,443,22,,C
Hardware,"Какие из этих устройств — устройства хранения?",SSD,RAM,HDD,CPU,,"A,C"
```

- **Первая строка — заголовок.** Названия колонок не важны, важен их
  порядок: первая — раздел, вторая — вопрос, последняя — ответ, все
  колонки между ними — варианты ответа (A, B, C, ... по порядку).
- **Раздел** — произвольный текст (тематический блок экзамена), по нему
  студенту показывается разбивка результата.
- **Варианты** — минимум 2 заполненных. Пустые ячейки пропускаются.
- **Ответ** — буква (`C`) или номер (`3`) варианта. Несколько правильных
  ответов перечисляются через запятую в кавычках (`"A,C"`), либо через
  `;` или пробел — такой вопрос становится multiple-choice (у студента
  чекбоксы вместо радиокнопок).
- Пустые строки игнорируются.

Название теста и проходной балл в файл не входят — они задаются в форме
загрузки (название по умолчанию берётся из имени файла).

## Как это используется в системе

1. Админ выбирает CSV-файл на странице загрузки → бэкенд проверяет его
   (`POST /api/tests/parse-preview`) и показывает предпросмотр или
   список ошибок с номерами строк.
2. Админ сохраняет тест (`POST /api/tests`) — вопросы, разделы и
   правильные ответы уходят в базу. Правильные ответы студенту никогда
   не отдаются до отправки его попытки.
